Reproducible analysis is not only about code. It also requires a stable folder structure, clear data provenance, documented decisions, and outputs that can be regenerated from source.

My preferred workflow separates raw data, cleaning scripts, modeling code, figures, tables, and manuscript text. This keeps the analytical path easier to review.
